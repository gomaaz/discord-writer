# Message sources

One file per showcase message, containing exactly the Discord raw text and
nothing else. Open a file, select all, copy, paste into Discord.

Do not add a fence around the content when copying. Several of these messages
contain ``` code blocks of their own, and an extra outer backtick turns the
whole post into a code block instead of a rendered message.

Filenames match the screenshots in `../images/`. See `../CAPTURE-GUIDE.md`.
