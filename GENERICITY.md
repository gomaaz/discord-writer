# Domain neutrality

`discord-writer` is a domain-neutral Discord rendering skill.

The base skill must not contain game-, product-, brand-, company-, or industry-specific default profiles or mandatory fields.

Domain-specific terminology may appear only when:

1. the user supplies it in the current request, or
2. the user explicitly defines it in their own guideline/profile.

Generic content profiles describe information shapes such as `component-set`, `changelog`, `procedure`, `schedule`, `status`, `comparison`, `faq`, and `reference-list`.
